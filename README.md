환경 구축

```bat
py -3.14 -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

설치 확인: 아래 명령어가 `Python 3.14.x`를 출력하면 됨.
```bat
.venv\Scripts\python --version
```

듀얼 모니터 전시 실행

```bat
.venv\Scripts\python dual_monitor.py
```

- 기존 `main.py`와 게임 UI·인식·점수 로직은 그대로 유지합니다.
- 전용 실행 파일은 메뉴 없이 기존 24개 단어 게임과 카메라 창을 즉시 엽니다.
- 첫 번째 화면에 카메라, 두 번째 화면에 게임을 최대화하여 표시하며 두 창 모두 항상 위에 표시합니다. 모니터는 OS에서 확장 모드로 설정해 주세요.
- 화면이 하나면 카메라는 왼쪽 1/3, 게임은 오른쪽 2/3에 배치합니다. 작은 화면에서는 기존 게임 UI를 스크롤하여 볼 수 있습니다.
- 카메라 창은 인식 스레드의 영상을 공유하므로 카메라를 중복으로 열지 않습니다. 기존 게임 동작에 따라 인식이 멈추면 영상도 마지막 프레임에 멈춥니다.
- 어느 창이든 닫거나 게임의 메인 메뉴 버튼을 누르면 두 창을 함께 닫습니다.
