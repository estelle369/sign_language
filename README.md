환경 구축

```bat
py -3.14 -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

설치 확인: 아래 명령어가 `Python 3.14.x`를 출력하면 됨.
```bat
.venv\Scripts\python --version
```

한 번 실행에 **단어 하나를 3번** 수집하고 끝남. 단어마다 예시 영상을 보고 동작을 익힌 뒤 다음 단어로 다시 실행.

**사람 번호**: 김건우 1, 정재우 2, 김시연 3을 나눠서 사용. **번호가 겹치면 파일이 섞이므로 반드시 다른 번호 사용.**

```bat
.venv\Scripts\python tools\collect_test_data.py --person 자기_번호 --word 단어_번호 --reps 3
```

- `--person`: 사람 번호
- `--word`: 수집할 단어 번호 (아래 표). 끝나면 다음 번호로 바꿔서 다시 실행
- `--reps`: 반복 횟수 (3)
- 카메라가 안 열리면("카메라를 열 수 없습니다") 확인할 것
  - 설정 → 개인 정보 및 보안 → 카메라 → "카메라 액세스", "데스크톱 앱이 카메라에 액세스하도록 허용" 켜기
  - 카메라를 쓰는 다른 프로그램(Zoom, Teams, 카메라 앱 등) 종료

### 5. 수집 방법

**카메라 구도 (중요)**
- 상체와 **차렷 자세로 내린 양손까지** 화면에 모두 들어오게 카메라를 놓음

**동작 하나의 흐름** (3번 반복 후 자동 종료)

| 화면 | 할 일 |
|---|---|
| `5 4 3 2 1` | 차렷 자세로 대기 |
| `STAND STILL` | 차렷 자세 유지 (쉬는 손 높이 측정) |
| `SIGN NOW` | 수어 동작 → **끝나면 반드시 차렷 자세로 복귀** |
| 초록 화면 `SAVED` | 저장 완료. 다음 반복으로 넘어감 |
| 빨간 화면 `MISSING - RETRY` | 손이 오래 안 잡힘. 같은 동작을 카운트다운부터 다시 |

- 손을 내려야(차렷 자세) 동작이 끝난 것으로 판단함. 동작 후 손을 들고 있으면 저장되지 않음
- 동작은 예시 영상처럼 자연스럽게 하면 됨
- `q` 키(수집 화면을 클릭한 상태에서): 중간 종료. 같은 단어로 다시 실행하면 **저장된 것은 건너뛰고 이어서** 수집함

### 6. 잘못한 동작 다시 하기

동작을 틀렸으면 해당 파일 2개(`.pkl`, `.mp4`)를 지우고 다시 실행하면 그 동작만 다시 수집함.

```
collected_data\samples\WORD0008\TEST02_1.pkl   ← 단어 0008, 2번 사람, 1번째
collected_data\samples\WORD0008\TEST02_1.mp4   ← 같은 동작의 키포인트 영상 (확인용)
```

### 7. 결과 보내기

수집이 끝나면 `collected_data` 폴더 안의 `samples` 폴더를 우클릭 → **압축(ZIP)** 해서 김건우에게 전달.
여러 사람의 `samples` 폴더는 파일 이름이 겹치지 않아 그대로 합칠 수 있음.
