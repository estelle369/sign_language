환경 구축

```bat
py -3.14 -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

설치 확인: 아래 명령어가 `Python 3.14.x`를 출력하면 됨.
```bat
.venv\Scripts\python --version
```

화면 조작

- 실행 시 전체화면으로 시작합니다.
- 메인·연습·게임 화면 어디서든 `F` 또는 `F11`을 누르면 전체화면으로, `Esc`를 누르면 일반 창 모드로 전환합니다.
- 실전 게임은 한 창에서 왼쪽 웹캠 영역 40%, 오른쪽 게임 영역 60%로 나뉩니다. 권장 해상도는 1280×800 이상입니다.
- 기존 모델이 지원하는 24개 단어를 4열×6행에 무작위 순서로 배치하며, 맞힌 단어는 사라지는 애니메이션을 재생합니다.
- 웹캠 미리보기는 인식용 카메라를 공유하며 약 30fps로 갱신합니다. 카메라 연결·영상 수신 또는 모델 로딩 실패 시 앱을 종료하지 않고 오류와 재시도 버튼을 표시합니다.
